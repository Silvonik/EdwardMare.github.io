Key To Build

Key To Build is a game where you try get as many blocks as you can on the Platform.

Unity | 3D | C#

About

The game is pretty boring its just press space and a block drops and you cant really control anything.

This was pretty much my first full game and I didn't use any tutorials while making the game to give me a challenge so thats why I made the game has such a basic and easy to build mechanic.

It was pretty okay making the game and it took me a week to make it but I learnt so much from this game and it was a good decision I made it.
